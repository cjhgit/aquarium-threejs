# 澄境 · STILLWATER

一个为放空而做的 Three.js 水族馆。风格化鱼群、轻摆的水草、沙地焦散、漂浮微粒和水下光束，全部由程序生成。

## 运行

直接用现代浏览器打开 `index.html`。无需 Node.js、npm、构建工具、服务器或网络。也可以将整个目录放到任意静态服务器。

## 互动

- **投喂**：点击工具栏「投喂」会撒下一把食物；随后点击水中继续投喂，再次点击按钮退出。鱼会主动靠近食物。
- **视角**：拖动转动视角，滚轮拉近 / 拉远。
- **环境**：三种光照氛围，鱼群数量、时间流速和画质均可调节。
- **声音**：开启后生成柔和的水下环境声，默认关闭。
- **快捷键**：`H` 隐藏 / 显示界面；`F` 全屏；`空格` 暂停 / 继续；`Esc` 关闭设置并退出投喂。

## 文件

- `index.html`：界面与入口
- `style.css`：响应式界面
- `aquarium.js`：场景、鱼群行为、程序化建模、着色器和交互
- `vendor/three.min.js`：Three.js r160，本地随附（MIT）

## 实现与性能

四种风格化鱼类包含程序化鱼鳞、分层鱼眼、鳃线、半透明鳍和鳍条。基于速度的摆尾、平滑转向、邻近避让及小鱼聚群，让每尾鱼保持自己的节奏。水草按区域合并网格，顶点着色器计算水流；焦散、沙粒和光束采用轻量程序着色器。气泡与悬浮颗粒分别批量绘制。鱼群上限 52，投喂数量有限；限制设备像素比，自适应降低分辨率，后台标签页暂停绘制。

建议使用开启硬件加速的 Chrome、Edge、Firefox 或 Safari。画面需要 WebGL；性能取决于设备，可在设置中选择「省电」。
