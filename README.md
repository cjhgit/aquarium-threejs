# 澄境 · STILLWATER

一个无需构建、可离线运行的 Three.js 水族馆。风格化鱼群、水草、沙地焦散、气泡与水下光束全部由程序生成。

## 运行

直接用现代浏览器打开 `index.html`。无需 Node.js、npm、构建工具、服务器或网络，也可将整个目录放到任意静态服务器。

## 操作

默认没有文字或常驻控件。鼠标移到画面底部中央显示工具栏，移开自动隐藏；触屏轻点底部区域唤出，稍后自动隐藏。键盘 Tab 也能访问按钮。

**点击水中哪里，就在哪里投下固定 3 颗鱼饵。** 没有投喂按钮或投喂模式；拖动只调整视角，点击工具栏或图鉴不会投食。食物缓慢下沉并落在沙地上。鱼每吃一颗会减速游开，休息 2.5 秒（场景时间）后才能再次进食；每次投下的三颗中，同一条鱼最多吃两颗，其余留给其他鱼。新一轮投喂重新计数，邻近投喂点合并排队也不会重置旧批次的上限。

底部图标从左到右：暂停、光照、鱼群数量、省电画质、鱼类图鉴、全屏。

- 光照依次切换日光、落日和夜色。
- 数量依次切换 14、26、34、42、54 尾；每档都有六种小鱼和固定两条大型鲨鱼。
- 图鉴支持切换鱼种、拖动旋转实际 3D 模型、查看特点和当前数量。缩略图与预览均由水族馆中的同一模型生成。
- 图鉴默认关闭，关闭后水族箱恢复无文字画面。按 Esc 或点击右上角关闭。
- 拖动调整视角，滚轮拉近 / 拉远。
- 快捷键：`G` 打开图鉴，`H` 隐藏 / 恢复工具栏，`F` 全屏，`空格` 暂停 / 继续。图鉴中左右方向键切换鱼种。

## 七种固定设计

这些是澄境的原创幻想鱼种。每种鱼的体态、配色、纹样和全部鳍型由一份固定设计共同决定，不交叉随机组合。个体只在整体大小（±6%）和游动节奏上存在差异，身体与鳍型不会随机混搭。

| 鱼种 | 体态与配色 | 标志性鳍型 |
| --- | --- | --- |
| 琥珀扇尾 | 暖金椭圆身 | 宽叉尾、折扇背鳍 |
| 青瓷帆鳍 | 湖蓝圆身与青色水纹 | 高帆背鳍、对称宽叉尾 |
| 月纱神仙 | 银杏白高身、墨绿竖纹 | 上下长帆鳍、一对长腹须 |
| 霞金绸尾 | 杏橙流线身、浅金斑 | 圆绸扇尾、低弧背鳍 |
| 碧潮燕尾 | 碧蓝流线身、后倾水纹 | 后掠背鳍、深叉燕尾 |
| 星河灯鱼 | 纤小青绿身、蓝红侧线 | 短背鳍、轻巧小叉尾 |
| 蓝礁巡游鲨 | 巨型银背白腹、宽圆吻部、自然闭合的下颌、五道鳃裂 | 低矮后掠镰形背鳍、宽胸鳍、紧凑的不对称尾鳍 |

鲨鱼全长超过初版的两倍，按礁鲨实拍重做侧面与俯视轮廓：短而扁宽的吻部、鳃后缓慢收窄的修长躯干、细尾柄和后掠长胸鳍。头部横向宽度与垂直高度分别建模；吻部由连续曲线收圆，使用适度加密的低多边形网格与清晰块面，侧面的最大宽度落在面内，避免横向尖棱；下颌闭合，仅保留贴肤唇线。所有鱼的虹膜、瞳孔与高光均投射贴合实际体表，不使用悬浮眼球。两条鲨鱼沿中后景的宽幅路线，以较慢的摆尾和宽转弯持续巡游，不争抢颗粒鱼饵。小鱼根据鲨鱼的体长与预判路径提前让路，近距离加速避开，远离后逐渐恢复自己的游动节奏。避让仅遍历两条鲨鱼，全部鱼类继续受实体碰撞约束。

鱼身完全不透明，鱼鳍只保留少量通透感。原版圆身宽尾鱼与后来的流线鱼都作为完整设计保留。

## 建模与运动

背鳍和腹鳍的整条根部，沿实际低多边形鱼身截面贴合并略微嵌入；自由波动从连接处逐渐向鳍尖增加。每种鱼生成时还会向真实鱼身网格发射射线，检查全部鳍根，避免固定高度带来的悬空。共享几何、纹理、着色器程序和同一模型工厂，确保图鉴与水族馆中的鱼完全一致；每尾鱼独立驱动摆尾相位与力度。

运动使用 60 Hz 固定物理步长，独立控制水平转向、有限俯仰与轻微倾斜，掉头不会翻肚。提前避让与覆盖身体、尾鳍、胸鳍的多轮碰撞约束防止相交；碰撞包络随俯仰转动。

每尾鱼独立交替巡游、滑行、短暂停留与短冲刺，目标水域会缓慢变化。小鱼有时松散同行，随后回到自己的路线，不向固定的鱼群中心聚拢。

鱼按视野方向和距离发现食物，短暂反应后明显加速追逐，并在接近鱼嘴时减速、吃掉食物。远处看不到食物的鱼不会全体加速。同一小团鱼饵由最合适的一条鱼优先进食，其他鱼提前让路，避免互相顶在食物外圈。一轮最多吃完 3 颗再游开，让同伴继续进食。接近时精确对准嘴部并减速，允许短暂后退和轻微升降，避免绕圈；吃到的鱼饵立即从场景及活动列表移除。鱼身与鱼鳍的摆动频率、幅度随真实游速变化，滑行时轻摆、追食时加快。

## 文件

- `index.html`：入口、隐藏工具栏与图鉴弹窗
- `style.css`：界面与手机布局
- `fish-species.js`：六种固定鱼种的完整设计与图鉴资料
- `aquarium.js`：场景、程序化建模、材质、图鉴及交互
- `fish-motion.js`：游动、避让与碰撞约束
- `vendor/three.min.js`：Three.js r160（MIT）
- `tests/motion.html`、`tests/motion-tests.js`：可直接在浏览器运行的运动回归检查

## 性能

水草合并网格并由 GPU 计算水流；岩石实例化；气泡与微粒批量绘制。鱼种共享几何、纹理与着色器程序；个体材质仅持有独立运动参数，全部鱼鳍合并绘制。图鉴仅在首次打开时创建预览上下文，关闭后停止预览绘制。限制设备像素比，自适应降低分辨率，后台标签页暂停绘制。

浏览器需支持 WebGL，建议开启硬件加速。Three.js: https://threejs.org/ · https://github.com/mrdoob/three.js/blob/r160/LICENSE

## 运动回归检查

直接打开 `tests/motion.html`，点击「运行检查」，无需 Node.js 或服务器。检查包括可见食物触发加速、不可见食物不影响鱼速、实际吃食后离开、独立变速、食物消失后散开，六种鱼在 42 个接近位置的实际吃食、每吃一颗休息 2.5 秒、同一批每鱼最多两颗且新一批重新计数、至少两条鱼分食三颗鱼饵、拥挤争食、前景与表层投喂，以及两条鲨鱼与 52 尾小鱼在三个固定随机种子下长时间共游、避让和追食的直立与碰撞约束。
