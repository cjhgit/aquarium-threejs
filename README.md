# 未来水族馆 · STILLWATER

一个无需构建、可离线运行的 Three.js 水族馆。风格化鱼群、水草、沙地焦散、气泡与水下光束全部由程序生成。

## 运行

直接用现代浏览器打开 `index.html`。无需 Node.js、npm、构建工具、服务器或网络，也可将整个目录放到任意静态服务器。

## 操作

默认没有文字或常驻控件。鼠标移到画面底部中央显示工具栏，移开自动隐藏；触屏轻点底部区域唤出，稍后自动隐藏。键盘 Tab 也能访问按钮。

**点击水中哪里，就在哪里投下固定 3 颗鱼饵。** 没有投喂按钮或投喂模式；拖动只调整视角，点击工具栏或图鉴不会投食。食物缓慢下沉并落在沙地上。鱼每吃一颗会减速游开，休息 2.5 秒（场景时间）后才能再次进食；每次投下的三颗中，同一条鱼最多吃两颗，其余留给其他鱼。新一轮投喂重新计数，邻近投喂点合并排队也不会重置旧批次的上限。

底部图标从左到右：暂停、光照、鱼群数量、省电画质、鱼类图鉴、全屏。

- 光照依次切换日光、落日和夜色。
- 数量依次切换 14、26、34、42、54 尾；每档都有七种小鱼和固定两条大型鲨鱼。
- 图鉴支持切换鱼种、拖动旋转实际 3D 模型、查看特点、当前数量，以及大小、聚集、危险、活跃、速度五项属性。属性以五级相对等级显示。缩略图与预览均由水族馆中的同一模型生成。
- 图鉴默认关闭，关闭后水族箱恢复无文字画面。按 Esc 或点击右上角关闭。
- 拖动调整视角，滚轮拉近 / 拉远。
- 快捷键：`G` 打开图鉴，`H` 隐藏 / 恢复工具栏，`F` 全屏，`空格` 暂停 / 继续。图鉴中左右方向键切换鱼种。

## 七种固定设计

这些是未来水族馆的原创幻想鱼种。每种鱼的体态、配色、纹样和全部鳍型由一份固定设计共同决定，不交叉随机组合。个体只在整体大小（±6%）和游动节奏上存在差异，身体与鳍型不会随机混搭。

| 鱼种 | 体态与配色 | 标志性鳍型 |
| --- | --- | --- |
| 琥珀扇尾 | 暖金椭圆身 | 宽叉尾、折扇背鳍 |
| 青瓷帆鳍 | 湖蓝圆身与青色水纹 | 高帆背鳍、对称宽叉尾 |
| 月纱神仙 | 银杏白高身、墨绿竖纹 | 上下长帆鳍、一对长腹须 |
| 霞金绸尾 | 杏橙流线身、浅金斑 | 圆绸扇尾、低弧背鳍 |
| 碧潮燕尾 | 碧蓝流线身、后倾水纹 | 后掠背鳍、深叉燕尾 |
| 星河灯鱼 | 纤小青绿身、蓝红侧线 | 短背鳍、轻巧小叉尾 |
| 蓝礁巡游鲨 | 巨型银背白腹、宽圆吻部、自然闭合的下颌、五道鳃裂 | 低矮后掠镰形背鳍、宽胸鳍、紧凑的不对称尾鳍 |

鲨鱼全长超过初版的两倍，按礁鲨实拍重做侧面与俯视轮廓：短而扁宽的吻部、鳃后缓慢收窄的修长躯干、细尾柄和后掠长胸鳍。头部横向宽度与垂直高度分别建模；吻部由连续曲线收圆，使用适度加密的低多边形网格与清晰块面，侧面的最大宽度落在面内，避免横向尖棱；下颌闭合，仅保留贴肤唇线。所有鱼的虹膜、瞳孔与高光均投射贴合实际体表，不使用悬浮眼球。两条鲨鱼沿中后景的宽幅路线，以较慢的摆尾和宽转弯持续巡游，不争抢颗粒鱼饵。小鱼根据鲨鱼的体长与预判路径提前让路，近距离加速避开，远离后逐渐恢复自己的游动节奏。避让仅遍历两条鲨鱼，全部鱼类继续受实体碰撞约束。

鱼身完全不透明，鱼鳍只保留少量通透感。原版圆身宽尾鱼与后来的流线鱼都作为完整设计保留。

## 建模与运动

背鳍和腹鳍的整条根部，沿实际低多边形鱼身截面贴合并略微嵌入；自由波动从连接处逐渐向鳍尖增加。每种鱼生成时还会向真实鱼身网格发射射线，检查全部鳍根，避免固定高度带来的悬空。共享几何、纹理、着色器程序和同一模型工厂，确保图鉴与水族馆中的鱼完全一致；每尾鱼独立驱动摆尾相位与力度。

身体由连续脊柱曲线驱动：头部保持稳定，躯干与尾部按转向速度和游速平滑弯曲，上浮、下潜时也有纵向跟随；直游后逐渐回正。鲨鱼在转弯收尾时逐渐降低转向速度，身体回正保留连续的变化速度，避免尾部突然甩回。行进波从躯干向尾部增强，鲨鱼采用更舒缓、明显的全身摆动。鱼鳍、眼睛、鳃线和嘴部共用同一变形，表面法线随脊柱方向转动；局部鳍尖仍保留柔性波动。变形在 GPU 上计算，无需逐帧重建网格。

运动使用 60 Hz 固定物理步长。合并巡游与避让指令后先平滑方向，再限制水平转向、俯仰的角加速度；目标位于正后方时保持同一掉头方向，避免反复甩头。小鱼与鲨鱼的身体弯曲均保持连续的变化速度。游动速度保留追食和逃离时的短促加速。鱼头先抬起或低下，再沿身体轴线升降，追逐正上方、正下方的食物时允许更明显的俯仰，保持背部朝上。提前避让与覆盖身体、尾鳍、胸鳍的多轮碰撞约束防止相交；碰撞纠正只做水平分离，不再将鱼体直接上下推移；贴近沙地和水面时提前调整俯仰，并沿游动轴线收速。碰撞包络随俯仰转动，鲨鱼使用沿弯曲脊柱和摆动波更新的四段胶囊链。

每尾鱼按鱼种活跃属性交替巡游、滑行、停留与短冲刺，目标水域会缓慢变化。碧潮燕尾活跃程度高，常在上层穿梭和短促冲刺；电光银梭的速度最高，在冲刺抵达与附近休息之间交替；月纱神仙活跃最低，无威胁时多数时间原处轻摆长鳍。星河灯鱼聚集最高，会主动靠近附近同类并跟随共同方向，落后时稍微提速，仍保留个体间距；其他小鱼更松散地同行。结群只跟随可见的邻近同类，不向全鱼群的固定中心聚拢。

蓝礁巡游鲨聚集最低、危险最高，接近同类时会主动拉开间距。所有小鱼都在鲨鱼身体碰撞范围之外提前警觉，越靠近越优先转向与加速远离；危险避让优先于结群和追食，危险区内的鱼饵会暂时放弃，远离后恢复各自的习性。

鱼按视野方向和距离发现食物，短暂反应后明显加速追逐，并在接近鱼嘴时减速、吃掉食物。远处看不到食物的鱼不会全体加速。同一小团鱼饵由最合适的一条鱼优先进食，其他鱼提前让路，避免互相顶在食物外圈。一轮最多吃完 3 颗再游开，让同伴继续进食。接近时精确对准嘴部并减速，允许沿身体轴线短暂后退，升降通过俯仰游动完成，避免水平鱼体侧滑下沉；吃到的鱼饵立即从场景及活动列表移除。鱼身与鱼鳍的摆动频率、幅度随真实游速变化，滑行时轻摆、追食时加快。

## 文件

- `index.html`：入口、隐藏工具栏与图鉴弹窗
- `style.css`：界面与手机布局
- `fish-species.js`：七种固定鱼种的完整设计、属性与图鉴资料
- `aquarium.js`：场景、程序化建模、材质、图鉴及交互
- `fish-motion.js`：游动、避让与碰撞约束
- `crab-rig.js`：宽扁蟹壳、三段关节步足、钳臂、眼柄与支撑足转向
- `turtle.js`：橄榄海龟的盾片背甲、桨状前鳍、滑翔节奏与中层巡游控制
- `vendor/three.min.js`：Three.js r160（MIT）
- `tests/motion.html`、`tests/motion-tests.js`：可直接在浏览器运行的运动回归检查

## 性能

水草合并网格并由 GPU 计算水流；岩石实例化；气泡与微粒批量绘制。鱼种共享几何、纹理与着色器程序；个体材质仅持有独立运动参数，全部鱼鳍合并绘制。图鉴仅在首次打开时创建预览上下文，关闭后停止预览绘制。限制设备像素比，自适应降低分辨率，后台标签页暂停绘制。

浏览器需支持 WebGL，建议开启硬件加速。Three.js: https://threejs.org/ · https://github.com/mrdoob/three.js/blob/r160/LICENSE

## 礁湾生态与居民习性

左侧礁区由宽大底石、两侧不规则石块和上方逐渐变小的石块堆叠而成，中央自然留出前后贯通的洞口；碰撞按各块石头的椭球包络计算。霞金绸尾偏爱礁洞，会在前后两侧往返。暖粉枝状珊瑚、紫色海扇采用不等长分叉与渐细枝条，避免等宽管线和规则网格；分布在礁脚与右侧沙地，合并静态网格以减少绘制开销。带多级细分叉的沉木平放在前景沙地。

新增 2 只青蟹、3 只扇贝、2 只海星、2 只水母和 1 只橄榄海龟；虾暂时从场景和图鉴隐藏，保留模型定义以便后续调整。这些居民不随鱼群密度按钮增殖。青蟹会交替停留、转向和横向探索，腿在侧向步态中交替伸展与抬起；扇贝缓慢开合、海星贴底缓行、水母收缩伞盖并在中上层漂移。程序化模型与动画在 `reef-life.js` 与 `turtle.js`，无需外部素材。

海龟对照 [WWF 绿海龟实拍](https://wwf.org.au/blogs/9-incredible-facts-about-green-sea-turtles/)重做：低拱椭圆背甲由五块中央盾片、两侧各四块肋盾和一圈缘盾组成，带深色鳞缝、细放射纹和甲缘包边；短颈连接圆钝头部，闭合喙嘴、嵌入式小眼睛与鼻孔贴合头部。头颈和四鳍采用本地程序生成的鳞纹，腹面保留浅色腹甲。长前鳍从宽厚鳍根逐渐收尖，左右同步下压，每轮约 4.6 秒，鳍尖柔性弯曲；划水与舒展滑翔平滑交替，后鳍负责掌舵，转弯时身体向内侧倾斜。它在中层开阔水域沿缓慢变化的路径巡游，绕开礁石与镜头；小鱼把它当作与礁石一样的实体障碍，从壳边让开。

图鉴展示十三种居民，新增偏爱环境、食性与习性。琥珀扇尾偏底层、碧潮燕尾偏上层、月纱神仙与星河灯鱼偏海草、霞金绸尾偏礁石，青瓷帆鳍与鲨鱼偏开阔中层。环境偏好驱动出生位置、巡游目标与温和的回归引导，鱼仍有不同高度的探索、进食与受惊避让行为。

鲨鱼巡游一段时间后，偶尔选附近一条小鱼追玩约 5–7 秒，靠近后提前结束，等待约 28–63 秒再尝试。不吞食或删除居民，也不争抢颗粒饵。减少鱼群数量后会立即放弃已经隐藏的目标。

运动回归检查新增水层偏好、礁洞往返与岩壁间距、追玩频率与结束条件，以及新增居民数量和活动区域验证。


碰撞模拟与可见模型使用独立的变换：岩壁和鱼体的分离约束交替求解；可见模型以受限的速度、加速度连续跟随，避免碰撞求解一帧内累计修正位置时产生突移。鲨鱼提速更缓慢，摆尾推力先增强，再逐渐提升速度；所有鱼的摆尾频率与幅度随游速及加速意图增加。新增回归覆盖青蟹的横向位移和停走周期、虾隐藏、碰撞大幅修正后的可见鲨鱼位移与加速度，以及堆石环境中的鱼群与岩壁间距。


青蟹的蟹壳、眼窝和钳形参考 [MarLIN 岸蟹正面与背面照片](https://www.marlin.ac.uk/species/detail/1497)。蟹壳为宽扁盾形，保留侧齿、背部隆脊、下缘与腹部甲片；缩小的眼睛随独立眼柄观察，钳臂包含肩、肘、腕关节，钳口从掌端铰点开合，两侧动作错开。

步足按三段可见肢段制作：第一段固定连接蟹身、第二段弯折支撑，最后一段短而尖。关节求解保持肢段长度与连接位置，支撑期把足尖锁定在沙地世界坐标，摆动期再抬脚、前送与落地；至少四只脚保持支撑。身体横向移动，转身绕落地足尖走弧线，其余步足交替重落脚，不再原地绕身体中心旋转。关节、钳口、眼柄、足尖锁定与支撑转向的检查覆盖 60 帧和 25 帧下的连续运动。图鉴与场景共用同一关节模型。


青蟹步足按四对等间距、左右对称排布，直行时各腿的落脚方向与身体横移方向一致。三段腿限制在同一竖直平面内，膝与末节只绕单一铰链轴屈伸；从正上方看，腿根、膝、末节与足尖共线，避免向前后折出的锯齿形。转身保留支撑足换步，迈步组会检查两组步足的重落脚需求，避免单只脚长期被当作支点而超过可达范围。新增检查覆盖静态排布、直行时前后漂移，以及行走与转向全过程中的俯视共线约束。


海龟模型专项检查：打开 `tests/turtle.html` 可同时查看透视、俯视、侧面和正面，暂停后拖动划鳍相位，或切换滑翔。点击「检查结构与运动」验证表面法线、鳍尖与封口、双鳍对称、鳍根固定、动画重复定位、纹理共享与独立动画、25 / 60 帧长时间巡游，以及自身移动障碍不会导致自我避让。材质纹理只生成一次，静态细节按材质合批，水族馆与图鉴共用同一模型。


水母危险属性为最高（5 级），伞盖与触须分别使用随自然漂浮更新的碰撞包络。其他鱼、鲨鱼和海龟提前远离水母；鱼群生成和切换密度时预留安全间距，水母附近的鱼饵不参与争抢，避让优先于追食、结群和追玩。移除接触时挤开水母及回漂补偿，水母位置只由自身缓慢漂浮决定。运动回归覆盖危险等级、各鱼种避让、各档密度初始间距、水母不受碰撞推移，以及不同帧率下的长期共游。`aquariumAudit().jellyfishGap` 可查看可见鲨鱼与水母包络的最小间距。


左右两侧的大型礁石、拱洞堆石与沙地散石均参与碰撞。石块从实际凹凸网格及旋转、缩放生成保守的有向椭球包络，避免显示石块和手填碰撞尺寸不一致。鲨鱼的躯干、背鳍、胸鳍与尾鳍分别参与礁石检测，避免将整条身体按背鳍高度加厚。可见模型会预判未来三秒的转弯和摆尾范围，提前调整目标速度，并以受限加速度连续避让。`aquariumAudit().rockGap` 返回可见鲨鱼到礁石碰撞包络的最小间距。


鲨鱼运行期间不再裁剪整组动作或强制退让，也不因碰撞清零速度、转向和摆尾时钟；摆尾振幅单独平滑，初始相位与模拟保持一致。页面与运动回归共用同一份包含 81 块石头的礁石生成逻辑；检查覆盖 25 / 60 帧与两种体型，在每个 60 Hz 物理步检查可见模型的速度变化、转向加速度、摆尾时钟和振幅连续性，并持续检查位移与礁石间距。

电光银梭是馆内速度最快的新鱼：银白尖吻梭形身体、细尾柄、低矮后掠鳍和窄镰形叉尾配合金色侧线。每条鱼独立选择相距较远的目的地，先低速对准方向，在约四分之一秒内蹬尾加速，冲刺约 1–2 秒；抵达前收住速度，在原处附近静息 24–42 秒再出发。投喂和危险避让仍优先。采用小体型，五档密度中数量为 1 / 2 / 2 / 2 / 3 条，默认两条，作为慢节奏中的偶发速度变化。冲刺时尾鳍上下叶平滑收拢约三成，刹停后恢复展开；银白侧腹与冷灰背部配合淡金侧线，材质保留柔和金属反光。普通鱼与电光银梭分别使用适合自身行为的加速度，图鉴使用相同模型。回归覆盖 25 / 60 帧、多个随机种子下的反复抵达、停留范围、可见速度与加速度，以及完整礁石布局中的高速混游。
